# Лабораторная работа: Функции

## Автор

Чупин Артем (Вариант 31)

## Цель

Научиться выделять повторяющиеся вычисления в функции с понятными параметрами и результатом, передавать массив вместе с его размером. Отделять ввод и вывод от вычислений, повторно использовать функцию для разных данных и явно обозначать отсутствие результата.

## Описание

Программа находит разницу между наибольшим и наименьшим элементом для каждого массива.

## Исходные данные

Три массива с произвольными элементами.

## Ожидаемые результаты

Программа выводит разность наибольшего и наименьшего элемента для каждого из трех массивов
